# Codex Pulse 1.2.0

Codex의 남은 사용량, 계정, 리셋권, 공개 리셋 달력을 보여주는 Windows C# WPF 위젯입니다. 펼침 360×480 / 접힘 1행 360×84·2행 360×112 논리 픽셀이며, 탭 없이 한 화면에 표시합니다.

## 실행

[최신 Releases](https://github.com/BTL-LaserInnovation/CodexPulse/releases/latest)에서 **BTL.CodexPulse-win-Setup.exe**를 다운로드하여 실행합니다. .NET 10 Desktop Runtime x64가 없으면 설치 과정에서 Microsoft 런타임을 다운로드하여 설치합니다. 인터넷 연결과 관리자 승인이 필요할 수 있으며, 이미 설치된 런타임은 다시 설치하지 않습니다. Codex 앱 또는 CLI는 별도로 설치하고 ChatGPT 계정으로 로그인해야 합니다. 위젯이 실제로 연결한 이메일과 플랜을 상단에서 확인하세요.

이전 단일 exe 사용자는 위젯을 종료한 뒤 설치형을 한 번 설치해야 앱 내 업데이트를 사용할 수 있습니다. 설치 위치는 `%LOCALAPPDATA%\BTL.CodexPulse`이며 기존 데이터 폴더 `%LOCALAPPDATA%\CodexPulse`와 분리됩니다. 기존 설정은 이어집니다.

선택한 C 시안(민트 막대와 리셋 화살표)을 exe 파일, 시스템 트레이, 메인 창 상단, 리셋권 확인창에 동일하게 적용했습니다. Windows 아이콘에는 16·20·24·32·40·48·64·128·256픽셀 이미지를 포함합니다.

다른 PC에 설치하면 그 PC에서 탐색한 `codex.exe`의 로그인 계정을 사용합니다. Codex 앱과 CLI의 로그인 계정이 다를 수 있으므로 표시된 이메일을 기준으로 확인합니다.

## 업데이트 및 배포

프로그램 시작 시와 실행 중 **5분마다** 업데이트를 확인합니다. Codex 사용량 조회(60초)와 독립적으로 동작합니다. 공개 Releases의 업데이트 파일을 직접 읽으며 앱에 GitHub 인증 토큰을 포함하지 않습니다. 사용자는 GitHub 계정이나 Git 설치가 필요 없습니다.

새 버전이 있으면 제목 오른쪽에 **Update** 버튼이 표시됩니다. 접힌 상태에서도 같은 위치이며 배경 투명도와 관계없이 선명합니다. 그라데이션은 천천히 변화하고, 업데이트가 없으면 버튼과 공간이 사라져 빈 영역으로 창을 이동할 수 있습니다.

버튼을 누르면 다운로드 진행률을 표시하고, 설정 저장 후 업데이트하여 재시작합니다. 실패하면 현재 프로그램을 유지하며 재시도할 수 있습니다. 리셋권 확인·사용·결과 재조회가 진행 중일 때는 적용을 보류합니다. 업데이트가 리셋권 요청을 새로 보내지 않습니다. 개발 빌드와 이전 단일 exe는 설치형 자동업데이트 대상이 아닙니다.

새 버전 배포는 프로젝트의 `<Version>`을 올리고 `release-notes/<버전>.md`를 작성한 다음 `main`에 올립니다. GitHub Actions가 Debug/Release 빌드·결정적 검사·설치 파일 생성을 실행하고, 해당 버전 태그가 없으면 `v<버전>` Release를 게시합니다. 같은 버전은 덮어쓰지 않습니다. 외부 PR은 게시하지 않습니다. 배포 인증에는 Actions 실행 토큰을 사용하며 앱에는 토큰을 넣지 않습니다.

`scripts/Build-Release.ps1`로 로컬 패키징도 가능합니다. 결과는 `publish/<버전>/releases`에 생성되며 Setup, 업데이트 패키지, `releases.win.json`, SHA256 목록을 포함합니다. 설치형은 `Installed.pubxml`로 framework-dependent 배포하고 `net10.0-x64-desktop` 설치 조건을 지정합니다. `Portable.pubxml`은 별도의 런타임 포함 단일 exe 개발 프로필로 유지합니다.

## 사용

- 위젯은 실행 시 화면에 표시되며 작업표시줄 버튼 없이 시스템 트레이 아이콘으로 동작합니다. Windows 설정에 따라 트레이의 숨겨진 아이콘 목록에 표시될 수 있습니다. 아이콘을 클릭하면 기존 위젯을 앞으로 가져오며, 리셋권 확인창이 열려 있으면 확인창을 앞으로 가져옵니다.
- 상단 **닫기(X)** 는 프로그램을 종료하고 트레이 아이콘도 제거합니다. 닫을 때 트레이로 숨기는 동작은 하지 않습니다.
- Windows 탐색기 재시작 알림을 받으면 트레이 아이콘을 다시 등록합니다. 트레이 등록에 실패하면 위젯에 실패 상태를 알리고 접근할 수 있도록 작업표시줄에 임시로 표시합니다.
- 제목뿐 아니라 계정·사용량·빈 배경을 잡고 창을 이동할 수 있습니다. 버튼, 체크박스, 슬라이더, 달력 날짜, 스크롤 목록은 원래 조작을 유지합니다.
- 상단의 **⌃ / ⌄** 아이콘으로 접기·펼치기를 전환합니다. 최소화 버튼은 없습니다.
- 접으면 고정, 불투명도와 실제 제공된 한도별 비율·막대·리셋 카운트다운을 표시합니다. 주간 한도가 있으면 첫 행에 두고, 다른 한도가 함께 제공되면 두 번째 행에 표시합니다. 이름은 `주간`·`5시간`·`일일` 등 실제 기간이며 기간 미상은 `사용 한도`입니다. 비율은 왼쪽, 남은 시간은 오른쪽에 두고 막대가 가운데 남는 폭을 채웁니다. 열 위치는 두 행에서 같고, 한도가 하나면 빈 두 번째 행을 만들지 않습니다. 한도 자료가 전혀 없으면 중립적인 정보 없음 상태를 표시합니다. 접혀도 갱신은 계속됩니다.
- **고정**은 다른 일반 창 위에 표시하는 옵션입니다. 상단 슬라이더는 배경 불투명도를 55–100%로 조절합니다. 창·카드·버튼 바탕만 투명해지고 글자·아이콘·테두리·체크박스·사용량 막대·조작 손잡이는 기존 선명도를 유지합니다. 접힌 화면과 리셋권 확인창도 같은 배경 값을 따릅니다.
- 비활성 버튼, 달력의 다른 달 날짜, 스크롤 손잡이의 기존 구분 효과는 유지합니다. 카드처럼 배경이 겹치는 부분은 합성되어 창의 빈 배경보다 진하게 보일 수 있습니다. 이전에 저장한 불투명도 값은 배경 설정으로 이어집니다.
- 계정·사용량·리셋권은 60초마다 갱신합니다. 연결 실패 시 계정과 비율을 이전 값으로 구분하고 리셋권 사용은 비활성화합니다.
- 사용 한도 카드의 제목은 서버 자료에 따라 표시합니다. 기간이 있으면 `주간 한도`·`5시간 한도`·`일일 한도` 등 실제 기간, 사용량만 있고 기간을 알 수 없으면 `사용 한도`, 한도 자료가 없으면 `한도 정보 없음`으로 표시합니다. 요금제 이름으로 한도 기간을 추정하지 않습니다.

## 리셋권

리셋권은 만료가 빠른 순서이며, 만료 시각을 제공하지 않은 항목은 마지막에 표시합니다. 목록은 이름·만료 시각·남은 시간·사용 버튼을 각각 고정 폭 열에 배치한 한 줄 형식입니다. 긴 이름은 말줄임 처리하며 전체 이름을 툴팁으로 확인할 수 있습니다. 마우스를 올리면 초 단위 만료 시각과 UTC 오프셋을 볼 수 있습니다. 항목이 많으면 목록 안에서 스크롤합니다.

**사용** 버튼은 확인창을 엽니다. 확인창에는 계정, 선택한 권, 만료 시각, 소모 안내가 표시됩니다. 버튼은 **[리셋권 사용] [취소]** 순서이며 취소가 오른쪽·기본 키보드 선택입니다. Enter/Escape로 취소할 수 있습니다.

확인 직후 계정과 선택한 권의 상태를 다시 조회합니다. 계정 변경 알림이 오면 열린 확인창의 사용 버튼이 비활성화됩니다. 만료·계정 변경·정보 변경 시 요청을 보내지 않습니다. 확인 후에는 선택한 ID와 하나의 요청 식별자로 한 번만 요청합니다. 결과가 불확실하면 동일한 요청 식별자를 보존하고 자동으로 새 요청을 보내지 않습니다.

서버가 개수만 제공하면 상세 목록을 만들지 않습니다. 일부 상세만 제공하는 경우 보유 수는 서버 값을 유지하고 제목 툴팁에서 일부만 제공되었음을 알립니다. 사용 성공 후 사용량, 다음 리셋과 리셋권을 함께 갱신합니다.

## 공개 리셋 달력

인터넷의 [OpenTheRank](https://opentherank.com/ko/codex-reset/) 공개 페이지를 5분 간격으로 조회합니다. OpenAI 공식 서비스가 아닌 제삼자 기록입니다. 최초 실행에서도 과거 공개 기록을 가져오며, 연결이 끊기면 마지막으로 저장한 OpenTheRank 자료를 표시합니다. 최근 기록 날짜와 수신 시각을 확인할 수 있습니다. 페이지가 생성 시각을 제공하지 않으므로 자료 생성 시각은 미제공으로 표시합니다.

- 민트 · 리셋: 출처 달력에 기록된 리셋 적용
- 바이올렛 · 리셋권: 공개 리셋권 지급 발표. 리셋과 함께 지급된 기록도 구분해 표시
- 하늘색 · 예고: 사전 예고 게시 시각. 적용 완료나 확정 적용 시각이 아님
- 코랄 · 내 예정: 연결된 계정에서 직접 조회한 다음 리셋 시각

선택한 날짜는 흰색 테두리와 옅은 흰색 배경으로 표시합니다. 날짜 안의 작은 색상 점은 기록 종류를 나타내므로, 리셋권이 있는 날짜를 선택해도 보라색 점은 유지됩니다. 선택 표시와 기록 색상을 구분해 볼 수 있습니다.

날짜를 선택하면 해당 기록을 보여주며, **출처 ↗**로 원문 또는 OpenTheRank 기록을 확인할 수 있습니다. 개인 감지 이력은 달력에 사용하지 않습니다. 공개 기록은 내 계정의 적용·지급을 확인한 자료가 아닙니다. 예고는 시간이 지나도 자동으로 적용 완료로 바뀌지 않습니다.

사전 예고의 ‘내일’, ‘앞으로 이틀’ 같은 문구로 미래 적용 날짜나 시각을 만들어내지 않습니다. 현재 출처에 별도의 확정 적용 일정 데이터가 없으므로 향후 공개 리셋 일정을 추측해 표시하지 않습니다. 내 계정의 다음 리셋은 Codex에서 직접 조회합니다.

1.1.3으로 업데이트하면 이전 AgentResets 달력 캐시는 폐기하고 OpenTheRank 자료로 새로 받습니다. 창 위치·불투명도·고정·접기·계정·리셋권 요청 정보는 유지합니다. 페이지 구조가 바뀌거나 잘못된 응답이 오면 기존 OpenTheRank 캐시를 유지하고 ‘이전 자료’로 표시합니다.

시각이 있는 자료는 모두 **PC의 Windows 시간대**로 변환하고 서머타임을 적용합니다. 시각 없이 날짜만 제공된 오래된 자료는 UTC 발표 날짜를 유지하며 '시각 미제공 · UTC 날짜'로 표시합니다. 실행 중 Windows 시간대 변경은 약 10초 안에 확인합니다.

## 저장 정보

위치, 접기, 고정, 불투명도, 마지막 사용량과 계정 이메일·플랜, 공개 자료 캐시, 결과 미확인 리셋 요청 식별자는 다음 파일에 저장합니다.

```text
%LOCALAPPDATA%\CodexPulse\widget-state.json
```

위젯은 인증 토큰을 직접 읽거나 저장하지 않습니다. 인증은 Codex 자체가 처리합니다. 공개 자료는 각 PC가 같은 원천에서 받아오며 별도의 개인 이력 동기화 서버는 사용하지 않습니다. `USAGEREMAINING_DATA_DIR` 환경 변수로 저장 위치를, `CODEX_EXECUTABLE`로 자동 탐색 대신 사용할 Codex를 지정할 수 있습니다.

## 개발·검증

Visual Studio에서 `UsageRemaining.sln`을 엽니다. .NET 10 SDK와 WPF 개발 도구가 필요합니다. 설치·업데이트는 MIT 라이선스의 **Velopack 1.2.161**을 사용합니다. SDK와 패키징 CLI 버전을 함께 유지하세요. 저작권·라이선스 원문은 `third-party/Velopack-LICENSE.txt`에 보관합니다.

```powershell
dotnet build UsageRemaining.sln -c Debug -p:Platform=x64 -m:1
dotnet build UsageRemaining.sln -c Release -p:Platform=x64 -m:1
dotnet publish src/UsageRemaining.Widget -c Release -p:PublishProfile=Portable
powershell -NoProfile -File scripts/Build-Release.ps1
dotnet run --project tests/UsageRemaining.Checks
dotnet run --project tests/UsageRemaining.Checks -- --ui-fixture
dotnet run --project tests/UsageRemaining.Checks -- --update-ui
dotnet run --project tests/UsageRemaining.Checks -- --live
dotnet run --project tests/UsageRemaining.Checks -- --ui
dotnet run --project tests/UsageRemaining.Checks -- --published
dotnet run --project tests/UsageRemaining.Checks -- --published-installed
dotnet run --project tests/UsageRemaining.Checks -- --calendar-live
dotnet run --project tests/UsageRemaining.Checks -- --compact-preview weekly
dotnet run --project tests/UsageRemaining.Checks -- --compact-preview five-hour
dotnet run --project tests/UsageRemaining.Checks -- --compact-preview daily
dotnet run --project tests/UsageRemaining.Checks -- --compact-preview unknown
```

`--compact-preview`는 검증 프로그램 자체의 가짜 Codex 프로세스와 독립된 `artifacts/compact-preview-state` 폴더를 사용하며 실제 계정에 연결하지 않습니다. 네 가지 시나리오의 실제 WPF 캡처는 `artifacts/compact-preview-{weekly|five-hour|daily|unknown}-{1.0,1.5}x.png`에 저장됩니다.

아이콘 원본은 `src/UsageRemaining.Widget/Assets/CodexPulse.source.png`에 보관합니다. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Build-AppIcon.ps1`로 그림을 변경하지 않고 다중 해상도 ICO를 재생성할 수 있습니다.

# Codex Pulse 1.3.3

Codex의 남은 사용량, 계정, 리셋권과 공개 리셋 기록을 한 화면에서 확인하는 Windows 위젯입니다. 1.3.0에는 Google 캘린더 양방향 일정 편집, 대한민국 공휴일 표시와 확장된 일정 목록이 추가되었습니다.

펼친 화면은 월간 달력에서 360×558, 주간 달력에서 360×408, 접힌 화면은 한도 수에 따라 360×84 또는 360×112 논리 픽셀입니다. 주간 한도는 민트, 다른 한도는 보라색으로 표시하며 펼침·접힘 화면에서 같은 색상을 사용합니다.

1.3.2에서는 달력 제목 왼쪽 화살표로 월 전체와 한 주를 전환합니다. 월간·주간 모두 일정 헤더를 한 줄로 정리하고, 목록은 두 행을 표시하며 초과하면 내부 스크롤을 사용합니다. 동기화 정보는 일정 새로고침 버튼의 툴팁에서 확인합니다. 일정목록과 리셋권 제목 사이에는 8 논리 픽셀 여백을 두었습니다. 구현·검증 이력은 [달력 검토 기록](docs/Calendar-Week-Local.md)을 참고하세요.

1.3.3에서는 Google 로그인 대기 중 `연결 취소`를 누르고 다시 시도할 수 있습니다. 5분 대기 제한이 지나도 재연결 가능한 상태로 돌아오며, 취소한 요청의 늦은 응답은 새 연결에 적용하지 않습니다. 펼친 양쪽 한도 카드에는 리셋 날짜·시각 한 줄을 표시해 창 높이를 14 논리 픽셀 줄였습니다. 팝업 배경 표시의 안정성도 개선했습니다. [구현·검증 기록](docs/GoogleLogin-Cancel-Local.md)

## 설치와 업데이트

[최신 Releases](https://github.com/BTL-LaserInnovation/CodexPulse/releases/latest)에서 **BTL.CodexPulse-win-Setup.exe 하나만** 다운로드해 실행하세요. 필요한 .NET 10 Desktop Runtime x64가 없으면 설치 프로그램이 Microsoft 런타임을 다운로드해 설치합니다. 이 과정에서 인터넷 연결과 관리자 승인이 필요할 수 있습니다.

이미 설치형을 사용하는 경우 위젯 오른쪽 위의 **Update** 버튼으로 업데이트할 수 있습니다. 시작 시와 실행 중 5분마다 새 버전을 확인하며, 다운로드 후 설정을 저장하고 재시작합니다. 실패하면 현재 버전을 유지하고 다시 시도할 수 있습니다. Google 일정 저장·삭제나 리셋권 처리가 진행 중이면 업데이트 적용을 보류합니다.

1.3.1부터 일반 GitHub 다운로드가 실패하면 공식 GitHub API 경로로 다시 받습니다. 이전 버전에서 **Retry**가 계속되면 위젯을 종료하고 최신 Setup을 한 번 실행하세요. 기존 설정과 Google 연결 정보는 설치 폴더와 별도로 보관하므로 제거하거나 데이터 폴더를 지울 필요가 없습니다. 기존 버전에는 이번 다운로드 보완이 없으므로 첫 업데이트는 원래 주소가 복구되거나 Setup을 사용해야 합니다.

이전 단일 실행 파일 사용자는 위젯을 종료한 뒤 Setup으로 한 번 설치하세요. 기존 설정은 이어집니다. GitHub 계정이나 Git 설치는 필요하지 않습니다.

Codex 앱 또는 CLI는 별도로 설치하고 ChatGPT 계정으로 로그인해야 합니다. 위젯 상단에 표시된 계정과 플랜을 확인하세요. 다른 PC에서는 해당 PC에 설치된 Codex의 로그인 계정을 사용합니다.

## Google 캘린더

**현재 Google 앱은 Testing 상태이며, 배포 담당자가 등록한 테스트 사용자만 연결할 수 있습니다. Google의 앱 공개·검증은 완료되지 않았습니다.** 일반 사용자 전체의 Google 로그인이 준비된 상태는 아닙니다. Google을 연결하지 않아도 Codex 사용량과 공개 리셋 달력은 사용할 수 있습니다.

배포용 데스크톱 앱 등록 정보가 설치본에 포함되어 있어 별도 설정 파일을 준비할 필요가 없습니다. 연결이 허용된 계정은 **Google 연결**에서 기본 브라우저로 로그인하고 접근 권한을 승인한 뒤 표시할 캘린더를 선택합니다. PC에 Google 캘린더 앱을 따로 설치할 필요는 없습니다.

- Google에서 변경한 일정은 실행 중 60초마다 가져오며, 새로 고침 버튼으로 즉시 조회할 수 있습니다.
- **＋**로 일정을 추가하고, 목록에서 일정을 눌러 제목·날짜·시간·종일·반복·알림을 편집합니다. 저장한 변경은 Google 캘린더에 반영됩니다.
- 날짜 입력칸의 달력 아이콘으로 날짜를 선택할 수 있습니다. 날짜 선택기와 펼침 목록은 메인 화면과 같은 색상·글꼴을 사용합니다.
- 목록 오른쪽 휴지통은 삭제 확인창을 바로 엽니다. 제목과 실제 날짜·시간을 확인한 뒤 삭제하며, 취소하면 삭제하지 않습니다. 반복 일정의 해당 회차에서 휴지통을 누르면 그 회차만 삭제합니다. 전체 반복 편집·삭제는 일정 편집창에서 구분해 처리합니다.
- 읽기 전용 일정과 공휴일은 수정·삭제할 수 없습니다. 대한민국 공휴일 날짜는 빨간색이며 기념일과 구분합니다.
- 연결 해제는 이 PC의 연결 정보만 제거하며 Google의 원본 일정을 삭제하지 않습니다.

자동 검증에는 가짜 일정과 가짜 OAuth 응답을 사용했습니다. 실제 계정의 연결·권한과 Google의 앱 공개·검증 상태는 별도로 확인해야 하며, 실제 개인 일정의 저장·삭제를 대신 검증한 결과는 아닙니다.

## 위젯 사용

- 같은 Windows 사용자·로그인 세션에서는 한 개만 실행합니다. 다시 실행하거나 트레이 아이콘을 누르면 기존 위젯 또는 열린 확인창을 앞으로 가져옵니다.
- **자동**은 Windows 로그인 시 실행하는 옵션입니다. 설치형의 기본값은 켜짐이며, 사용자가 끈 선택은 업데이트 후에도 유지됩니다.
- **고정**은 다른 일반 창 위에 표시합니다. 배경 불투명도는 55–100%로 조절할 수 있고, 글자·아이콘·사용량 막대의 선명도는 유지합니다. 모든 대화상자와 내부 날짜 선택기·펼침 목록은 항상 불투명합니다.
- **⌃ / ⌄**로 접고 펼칩니다. 접혀도 사용량 갱신은 계속되며, 주간 한도가 있으면 첫 행에 표시합니다. 한도 자료가 없으면 정보 없음 상태를 표시합니다.
- 제목·계정·사용량·빈 배경을 잡고 창을 이동할 수 있습니다. 버튼·날짜·스크롤 목록은 각 조작으로 동작합니다.
- 작업표시줄 버튼 대신 시스템 트레이 아이콘을 사용합니다. **닫기(X)** 를 누르면 프로그램을 종료하고 트레이 아이콘도 제거합니다.
- 계정·사용량·리셋권은 60초마다 갱신합니다. 연결 실패 시 이전 자료임을 알리고 리셋권 사용을 비활성화합니다.

## 리셋권과 공개 리셋 달력

리셋권은 만료가 빠른 순서로 표시합니다. **사용**을 누르면 계정·선택한 권·만료 시각을 확인하는 창이 열리며 기본 키보드 선택은 취소입니다. 사용 직전 계정과 권의 상태를 다시 확인하고, 결과가 불확실한 요청을 자동으로 새로 보내지 않습니다.

공개 리셋 달력은 [OpenTheRank](https://opentherank.com/ko/codex-reset/)의 기록을 5분마다 가져옵니다. OpenAI 공식 서비스가 아닌 제삼자 자료이며, 내 계정에 리셋이나 리셋권 지급이 적용되었다는 확인은 아닙니다. 연결이 끊기면 마지막 저장 자료임을 표시합니다.

- 민트: 공개 리셋 기록
- 보라색: 공개 리셋권 지급 발표
- 하늘색: 사전 예고 게시 시각
- 코랄: 연결된 내 계정의 다음 리셋 시각

날짜를 선택하면 해당 기록을 확인하고 **출처 ↗**로 원문을 열 수 있습니다. 흰색 선택 표시와 기록의 색상 점은 구분됩니다. 사전 예고 문구로 미래 적용 시각을 추정하거나 시간이 지났다는 이유로 적용 완료로 바꾸지 않습니다.

시각이 있는 기록은 PC의 Windows 시간대와 서머타임을 적용합니다. 날짜만 제공된 기록은 원래 UTC 날짜와 시각 미제공 표시를 유지합니다.

## 저장 정보

창 위치·접기·자동실행·고정·불투명도, 마지막 계정·사용량, 공개 자료 캐시와 결과 미확인 리셋 요청 정보는 `%LOCALAPPDATA%\CodexPulse\widget-state.json`에 저장됩니다. 앱 설치 폴더는 `%LOCALAPPDATA%\BTL.CodexPulse`입니다.

Codex 인증은 Codex 자체가 처리하며 위젯이 Codex 인증 토큰을 직접 읽거나 저장하지 않습니다. Google 연결 정보는 별도로 Windows 사용자 보호 저장소(DPAPI)를 사용해 `%LOCALAPPDATA%\CodexPulse\google-auth\credentials.dpapi`에 저장합니다. 비밀번호는 위젯에 입력하지 않습니다. 공개 리셋 자료는 각 PC에서 가져오며 별도의 개인 이력 동기화 서버는 사용하지 않습니다.

## 개발과 배포

Google 데스크톱 앱 등록 정보는 소스에 커밋하지 않고 GitHub Actions의 `GOOGLE_DESKTOP_CLIENT_JSON` 저장소 비밀 설정에서 빌드 시 주입합니다. 이 값은 Google이 발급한 데스크톱 등록 JSON 전체 또는 `installed.client_id`와 `installed.client_secret`만 담은 JSON입니다. 로컬에서는 `-GoogleConfigurationPath` 또는 Git에서 제외된 `config/google-desktop-client.json`으로 전달할 수 있습니다. 공개 클라이언트인 데스크톱 앱의 등록 정보는 설치본에서 추출할 수 있으며 사용자 로그인 토큰이나 비밀번호가 아닙니다. 빌드는 두 등록 필드만 설치 폴더에 복사하고 개인 상태·인증 파일은 거부합니다. 사용자 토큰은 각 PC에서 로그인한 뒤 별도로 생성·보호됩니다. 외부 기여의 PR 빌드에는 배포용 등록 정보를 제공하지 않습니다.

Visual Studio에서 `UsageRemaining.sln`을 엽니다. .NET 10 SDK와 WPF 개발 도구가 필요하며, 설치·업데이트에는 Velopack 1.2.161을 사용합니다. 라이선스는 [third-party/Velopack-LICENSE.txt](third-party/Velopack-LICENSE.txt)에 있습니다.

```powershell
dotnet build UsageRemaining.sln -c Debug -p:Platform=x64 -m:1
dotnet build UsageRemaining.sln -c Release -p:Platform=x64 -m:1
dotnet run --project tests/UsageRemaining.Checks
dotnet run --project tests/UsageRemaining.Checks -- --google-ui
dotnet run --project tests/UsageRemaining.Checks -- --google-oauth
dotnet run --project tests/UsageRemaining.Checks -- --ui-fixture
powershell -NoProfile -File scripts/Build-Release.ps1
```

공개 배포는 프로젝트 버전과 `release-notes/<버전>.md`를 갱신해 `main`에 반영하면 GitHub Actions가 빌드·검사·패키징 후 새 버전 Release를 게시하는 방식입니다. 기존 버전은 덮어쓰지 않습니다. 로컬 패키징 결과는 `publish/<버전>/releases`에 생성됩니다.

공개 Release에 업로드하는 파일은 **Setup 설치 파일, full 업데이트 패키지, `releases.win.json` 세 개**입니다. 사용자는 Setup만 받으면 됩니다. 나머지 두 파일은 앱 내 업데이트용이며, 자동 표시되는 Source code 압축본은 실행 파일이 아닙니다. 업데이트 패키지는 피드의 SHA256과 크기로 확인합니다. 앱에 GitHub 인증 토큰을 포함하지 않습니다.

1.3.0 기능의 로컬 검증에서는 기본 검사 245개, Google UI 검사 173개, 기본+가짜 OAuth 루프백 검사 288개, 기존 전체 UI 검사 205개를 통과했습니다. 가짜 서비스 검사와 실제 계정 검증은 구분합니다. 과거 로컬 검토판의 재현 절차와 검증 이력은 [로컬 검토 기록](docs/GoogleCalendar-Local.md)에 보관합니다.

# Codex Pulse 1.3.3

- 브라우저에서 Google 로그인을 중단했을 때 위젯의 **연결 취소**를 눌러 앱을 다시 시작하지 않고 재시도할 수 있습니다. 5분이 지나면 연결 대기를 끝내고 다시 시도할 수 있도록 안내합니다.
- 취소한 로그인 창의 늦은 응답이 새 연결 정보나 캘린더 상태를 덮어쓰지 않도록 보완했습니다. 로그인 성공 후에는 연결 대기 타이머를 종료하며, 앱을 닫을 때 진행 중인 연결과 저장 정리를 마칩니다.
- 펼친 화면의 두 사용 한도 카드에서 초기화 시각을 현지 시간 기준 **MM-dd HH:mm** 한 줄로 표시합니다. 카드 영역을 14 DIP 줄여 위젯 높이가 월간 558 DIP, 주간 408 DIP가 되었습니다. 접힌 화면은 유지합니다.
- Google 일정 편집기의 캘린더 선택 목록 배경이 리소스 수명에 따라 사라질 수 있는 문제를 수정했습니다.

기존 Google 연결 정보와 사용자 설정은 유지합니다. 앱의 **Update** 버튼이나 최신 **BTL.CodexPulse-win-Setup.exe**로 업데이트할 수 있습니다.

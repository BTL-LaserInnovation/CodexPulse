# Codex Pulse 1.3.0

- Google 캘린더를 연결해 일정을 확인하고 추가·수정·삭제할 수 있습니다. 종일·반복 일정과 알림을 지원하며 Google의 변경 사항도 가져옵니다.
- 배포용 Google 데스크톱 앱 등록 정보를 포함해 별도 설정 파일 없이 로그인 절차를 시작할 수 있습니다. 사용자 로그인 토큰·비밀번호·개인 일정은 설치본에 포함하지 않습니다.
- 펼친 위젯을 360×604로 넓혀 일정 목록을 확장했습니다. 날짜 박스와 연속 일정 막대를 분리하고 대한민국 공휴일을 빨간색으로 표시합니다.
- 일정 편집에 같은 테마의 날짜 선택기를 추가했습니다. 모든 대화상자·날짜 선택기·펼침 목록은 메인 배경 투명도와 관계없이 불투명하게 표시합니다.
- 일정 목록의 휴지통에서 바로 삭제를 확인할 수 있습니다. 반복 일정의 해당 회차에서는 선택한 회차만 삭제합니다.
- 주간 한도는 민트, 다른 한도는 보라색으로 펼침·접힘 화면의 색상을 통일했습니다.
- 기존 자동실행, 단일 실행, 트레이, 설정 유지와 앱 내 업데이트 기능을 유지합니다.

**Google 연결은 현재 Testing 상태의 앱에 등록된 테스트 사용자로 제한됩니다. Google의 앱 공개·검증은 완료되지 않았으며 모든 사용자에게 로그인을 제공하는 상태는 아닙니다.** Google 미연결 상태에서도 Codex 사용량과 공개 리셋 달력은 사용할 수 있습니다.

기존 설치 사용자는 **Update** 버튼으로 업데이트하세요. 새 설치에는 **BTL.CodexPulse-win-Setup.exe 하나만** 필요합니다. 필요한 .NET Desktop Runtime은 설치 프로그램이 준비합니다.

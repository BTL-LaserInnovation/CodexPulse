# Codex Pulse 1.2.1

- 제목줄에 **자동** 체크박스를 추가했습니다. 체크하면 Windows 로그인 시 실행하며 기본값은 켜짐입니다.
- 해제한 자동실행 설정은 재시작과 업데이트 후에도 유지합니다. 프로그램 제거 시 자동실행 등록도 정리합니다.
- 제목줄 좌우 여백을 활용해 자동·고정 옵션을 나란히 배치했습니다. 창 폭 360px, 투명도 슬라이더 36px와 기존 버튼 크기는 그대로입니다.
- 자동실행 등록 또는 설정 저장 실패 시 이전 선택으로 복원하고 상태와 툴팁에 안내합니다.

기존 설치 사용자는 제목 오른쪽에 표시되는 **Update** 버튼으로 업데이트할 수 있습니다. 새로 설치하려면 `BTL.CodexPulse-win-Setup.exe`만 다운로드하세요.

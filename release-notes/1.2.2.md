# Codex Pulse 1.2.2

- 자동실행과 수동실행이 겹쳐 위젯이 여러 개 뜨는 문제를 수정했습니다. 같은 Windows 사용자·로그인 세션에서 한 개만 실행합니다.
- 다시 실행하면 새 창을 만들지 않고 기존 위젯을 앞으로 가져옵니다. 리셋권 확인창이 열려 있으면 해당 확인창을 표시합니다.
- 창 위치, 접힘, 자동실행, 상단 고정, 배경 투명도 설정을 유지합니다.
- 설치·업데이트 훅은 기존대로 처리하며 위젯 종료와 재시작 사이에도 중복 실행을 차단합니다.

기존 설치 사용자는 **Update** 버튼으로 업데이트할 수 있습니다. 중복 실행 방지가 없던 구버전 창이 남아 있다면 모두 종료한 뒤 새 버전을 실행하세요. 새 설치에는 `BTL.CodexPulse-win-Setup.exe`만 필요합니다.

# Codex Pulse 1.3.1

- GitHub의 일반 다운로드 경로가 HTTP 오류나 시간 초과로 실패하면 공식 GitHub API 경로로 다시 다운로드합니다. GitHub 로그인이나 토큰은 필요하지 않습니다.
- 업데이트는 확인한 정확한 버전의 패키지를 받으며, 기존 파일 크기·SHA256 검증을 통과한 뒤 적용합니다. 취소하면 추가 다운로드와 적용을 중단합니다.
- 기존 Google 캘린더, 계정·리셋권, 표시 설정과 업데이트 버튼 UI는 유지합니다.

**1.2.2 또는 1.3.0에서 Update가 Retry로 바뀌며 업데이트되지 않는 경우:** 기존 버전에는 이번 다운로드 보완이 들어 있지 않습니다. Codex Pulse를 종료하고 최신 **BTL.CodexPulse-win-Setup.exe**를 한 번 실행해 업데이트하세요. 제거하거나 사용자 데이터 폴더를 지울 필요가 없습니다. 설치 위치와 별도로 보관되는 기존 설정과 Google 연결 정보를 계속 사용합니다. 이후 버전부터는 보완된 앱 내 업데이트 경로를 사용합니다.

Google 연결은 여전히 Testing 상태의 앱에 등록된 테스트 사용자로 제한됩니다.

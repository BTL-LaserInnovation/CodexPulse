# Codex Pulse 1.2.0

- Windows x64 설치형 배포. .NET 10 Desktop Runtime이 없으면 설치 과정에서 다운로드하여 설치합니다.
- 프로그램 시작 시와 실행 중 5분마다 업데이트를 확인합니다.
- 새 버전이 있으면 제목 오른쪽에 Update 버튼이 표시됩니다. 누르면 다운로드 후 업데이트하고 재시작합니다.
- Update 버튼은 배경 투명도에 영향을 받지 않으며 부드러운 그라데이션으로 표시됩니다.
- 창 위치, 접기, 고정, 배경 투명도와 기존 저장 정보를 유지합니다.
- 리셋권 확인·사용 중에는 업데이트 적용을 보류합니다.

처음 설치할 때는 `BTL.CodexPulse-win-Setup.exe`를 다운로드해 실행하세요. 기존 단일 exe 사용자는 위젯을 종료한 뒤 설치형을 한 번 설치해야 이후 앱 내 업데이트를 사용할 수 있습니다. Codex 설치와 계정 로그인은 별도로 필요합니다.

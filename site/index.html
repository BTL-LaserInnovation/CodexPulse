03 · CALENDAR

Google 일정 양방향 연결

선택한 캘린더의 일정을 보고 추가·수정·삭제합니다. Google 캘린더에서 바꾼 일정도 새로 가져옵니다.

접기·펼치기, 상단 고정, 배경 투명도, Windows 자동실행과 트레이를 지원합니다. 시간은 PC의 시간대를 따릅니다.

Google 연결은 선택입니다.

Google의 로그인 화면에서 직접 계정을 선택하고 권한을 승인합니다. Codex Pulse에 Google 비밀번호를 입력하지 않습니다. 연결하지 않아도 Codex 사용량과 공개 리셋 달력은 사용할 수 있습니다.

현재 Google 연결은 테스트 운영 중입니다. 앱에 등록된 테스트 사용자만 연결할 수 있으며 Google의 공개 검증은 아직 완료되지 않았습니다. 설치 파일을 받았다는 이유만으로 모든 Google 계정의 연결이 허용되는 것은 아닙니다.

요청하는 Google 권한과 사용 목적

권한사용 목적
openid · email연결한 Google 계정의 이메일을 표시하고 계정을 구분합니다.
캘린더 목록 읽기사용자가 연결할 캘린더를 선택하고 이름·시간대·접근 권한을 확인합니다.
캘린더 일정 보기·편집일정을 표시하고 사용자가 요청한 일정 추가·수정·삭제를 Google 캘린더에 반영합니다. 읽기 전용 캘린더에는 쓰지 않습니다.

데이터의 사용·저장·삭제 방법은 개인정보처리방침에서 확인하세요.

설치와 도움말

GitHub 계정 없이 설치 파일을 다운로드할 수 있습니다. 기존 설치형에서는 Update 버튼으로 업데이트합니다. 이전 버전에서 Retry가 반복되면 앱을 종료하고 최신 설치 파일을 한 번 실행하세요.
